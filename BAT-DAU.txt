BAT DAU VOI WEBSITE BAN TIN MOC.
===============================

1. Mo thu muc nay, bam dup vao index.html de xem web.
2. De dua web len mang: doc HUONG-DAN-TU-A-DEN-Z.md, lam Phan B -> C -> D.
3. Quan trong: chi upload cac file BEN TRONG thu muc nay len GitHub,
   de index.html o cap goc cua repository, khong upload moi file ZIP.
4. Doi ten bao, bai viet: assets/js/data.js
5. Doi mau: assets/css/style.css (4 ma HEX o dau file)
6. Website demo, khong phai bao chi that; cac bai viet deu la noi dung minh hoa.

Website hoat dong voi GitHub Pages public repository va GitHub Free, khong can tra phi.
